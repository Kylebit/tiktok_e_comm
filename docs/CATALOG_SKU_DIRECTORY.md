# 商品目录六列与 SKU 成本

页面仅展示主图、SKU、商品名称、规格、一个成本价、重量。原平台分组列、推送和维护控件已从页面代码移除。平台适配、旧目录 API、历史记录继续保留。

按用户明确授权，目录以内部 SKU 聚合，不因国家、平台或发布身份拆行。1–4 位纯数字补齐四位；66/77/88/99 + 四位内部码的规范六位国家别名去除该两位前缀。例如 0001、660001、770001、880001、990001 均显示 0001。其他非空商家 SKU 保留完整文本，不截断任意长字符串、平台 ID 或后缀规格。缺 SKU 的记录仍按完整身份单独保留。所有外部身份在后台多对一关联，不删除。

旧官方 global/unbound 实体中的已保存人工成本作为合并来源保留，不被旧原始成本覆盖。不同来源金额冲突在唯一内部 SKU 成本字段待选择；相同值共享读取。目录与利润均在保存前使用同一内部解析规则，不因未创建新成本表回退到每个平台不同金额。展示一份名称、规格与重量；主图依次尝试同一内部 SKU 已有图片候选，成功后停止，不借用其他内部 SKU 的图。

`catalog_sku_costs` 保存一份当前实体成本与版本；`catalog_sku_cost_history` 记录每次明确保存的来源、旧值、成员身份。原 `sku_costs`、`catalog_identity_costs`、审批与发布快照不删除、不改写。没有当前实体成本时，读取唯一身份的已有来源；只有各来源值相同才展示该值，不同值展示待选择，缺失不填默认。保存使用成员、源成本和版本的摘要 CAS，过期页面必须重新读取。旧身份成本写入口在已有实体成本时也消费同一写入逻辑。

身份成本读入口与利润审计读取同一当前实体成本；发布回流保留人工实体成本。利润原有完整身份核验仍生效，同名身份歧义不会因为成本相同而自动放行。历史审批和已冻结利润版本不重写。

图片读取仅接受启动时从同一审核副本登记的图片摘要键，不接受请求者指定 URL。HTTPS、无账号凭据、公开 DNS 地址、固定解析后 IP 并验证原主机 TLS、拒绝重定向、限制每图 8 MiB/40M 像素/8 秒、4 并发与总缓存 256 MiB、验证可解码图片类型。缓存与失败缓存仅在本次预览状态目录。不存在、失效或被拒绝的原图明确标注，不以占位图计为成功。图片读取授权不会启用平台 API 或凭据刷新。

真实审核副本沿用原文件，不重新采集覆盖。成本写入只在 fixture 验证，实际商品副本没有被测试修改。真实图片验证仅代表实际测试样本，不保证所有历史 URL 仍有效。
