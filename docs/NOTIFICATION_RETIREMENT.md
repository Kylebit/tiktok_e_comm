# 通知退役进度

用户已明确删除飞书与通知。当前首包删除应用机器人、HTTP 回调、日报 CLI/API、工作台通知和飞书消息导入入口，以及它们独有的 Lark SDK 依赖、配置示例和可发现条目。任务状态、审批事实和本地审计事件继续保存；历史数据库与通知事件不做迁移或清空。

旧 MX 对话确认只输出本地文字，不再自动发送通知。上架文字图片 Skill、平台适配、开发中的视频底层未修改。`modules.hub.tokens` 是平台凭据管理的共享组件，继续保留。

后继发送器包已删除独立 MX/UK 飞书派发/回放脚本、通用 webhook/app transport、LinkFox 卡片发送脚本及 stage2 飞书适配演示；`random_region_dispatch` 依赖已删除的旧 MX 卡片构建器，也随该旧链路退役。原 stage1 本地任务历史、协议映射和报告继续保留。

后续包已退役旧 MX/UK 页面、API、CLI 和内容独立入口。本次清尾进一步删除无调用方的 A2A/EigenFlux 外部消息原型、仓库级静态服务器和能力目录入口，并把历史验证报告移入 `docs/legacy/notifications/`。MX/UK 人工覆盖代码改用中性名称和新文件名；为避免丢失历史定价/物流事实，仅保留旧数据文件名的只读兼容。Ozon 同样只保留旧键名的路径读取兼容；两者都不包含连接、发送或回调能力。

当前源码不包含 Lark SDK 依赖，不提供外部通知 CLI、页面、能力卡、发送器或可启动服务。旧 HTTP 地址只以 404 tombstone 留在主服务，防止历史客户端误写；它们不是可执行入口。

当前包仅离线源码候选；部署以固定提交及独立验收为准。
