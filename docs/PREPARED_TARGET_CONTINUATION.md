# Prepared task continuation boundary

An expired lease is not a stopped writer. Cancellation checks the retained task
state, worker and lease fields without calling expiry, including when returning
the cancelled task projection. Cancelling one idle task cannot expire another.
Every domain operation whose state is not `completed` blocks cancellation intake.

The inert marketplace compiler accepts an exact pinned target reduction through
its internal Python seam. It preserves complete R1/R2 documents and COMMON input,
derives only retained target maps and carries the immutable cancellation record.
Quality reconstruction independently checks its original offer, R2 identity,
scope and digest. A removed Ozon target has no stock-decision requirement.

This seam does not activate an original-task receiver, consume a cancellation
from the operations ledger, authorize COMMON, or admit marketplace execution.
No HTTP route exposes its parameter. The existing stored domain graph still
refuses a reduced plan, and dispatch remains held until a separately reviewed
consumer reads the durable record and exact original-task ownership itself.
Changing a payload or setting `consumer_adopted` cannot remove that hold.

The current original-category recovery protocol can inspect retained receiver
continuity, but its normal `claim-original` requires a queued original owner or
a valid running lease. `heartbeat-original`, capture and freeze require that
valid lease. Its rollback revokes category continuity; it does not retire a
writer or clear an expired running task. Initial prepared-release adoption is
restricted to pre-intake failed facts tasks and cannot adopt this later history.

The service owner's exact-run `STOP.json` is a supported owned Windows Job
retirement request. Accept only a fresh matching owner and its genuine
`STEADY_RETIRED` receipt with zero active members and confirmed child exit;
`RETIREMENT_UNKNOWN` blocks replacement. This stops the owned web Job, not the
delegated product task. Do not fabricate a task lifecycle event from that receipt.
