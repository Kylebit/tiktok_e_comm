# 上架来源与只读接管合同

本合同统一三轮的**只读接管入口**。它不宣称个人较新 manual intake、自动批准及全部 R2/R3 工作流已经迁入当前运行版本。有效动作仍服从当前用户的具体授权、已实现运行合同及精确快照；旧文档例子不能撤销当前授权，也不能扩大为平台发布权。

## 接管一件已有商品

在明确工程中执行该工程的脚本，使用核验过的完整提交与数据根：

```text
python -B scripts/publication_takeover.py --expected-commit <40位提交> --data-root <已有资料的绝对工程根> --offer-id <数字商品ID>
```

此命令仅输出 JSON，不创建/更新商品、审批、数据库、报告或付费任务。不会启动服务或补建缺失 workbench，也不会自动导入数据根中的 Python。缺资料返回 `TAKEOVER_REJECTED`，不能以读取失败触发采集或发布。输出包含当前三轮全部受管理文件哈希、实际读取文件哈希与代码根/提交，缓存不进入技能内容；工作树是否干净单独呈现，未提交修改不能冒称提交内容。

先核商品 ID、Seller SKU、标题、冻结摘要、完整目标及 Product Center approval/fingerprint。第一轮自动决策凭证须与冻结快照和当前 approval 相互绑定；它是历史决策证据，接管不会重新批准，也不凭缺少当前政策文件撤销旧事实。修改过的当前 first-review 与旧冻结事实分别报告，R2 不重审 R1 商务事实。

生成状态、keep/人工采用、自动 QA 和最终发布批准不是同一状态。接管只显示历史资产数量、记录状态、未知标记及付费账本，不把 COMPLETED 转换为 keep，不把旧账本当成本轮 provider 对账。历史失败留存，新授权另行记录；未知任务先按 durable ID 对账。没有完整有效终审候选批准，不执行商城发布。

接管的 `r2_consumer` 使用 R3 实际消费合同检查完整 R1/R2 身份，不能用单个
`PASS`/`PASSED` 字样代替。它同时显示已记录的失败 QA 项，不修改旧回执。
对独立冻结的页脚本地化修正，可额外指定
`--r2-candidate-binding <绝对路径> --expected-candidate-sha256 <64位SHA256>`。
这会核验当前批准身份、完整翻译任务、母图/输出字节和页脚外像素，并返回逐候选的
目标映射。结果只进入 `pending_r2_candidate`，`keep_count=0`、`r3_ready=false`；
不会替换正式 R2 图序、QA、发布路由或批准。候选、来源或 revision 漂移均拒绝。
`protected_region` 和 `footer_region` 均使用 PIL 半开矩形 `[left, top, right, bottom)`；
`bottom` 行已在 footer 外，必须与母图一致。生成器若使用包含终点的坐标，须在形成
新 manifest 前显式转换，重新冻结 manifest/binding 摘要；不能默默放宽旧候选边界。
该命令只写标准输出，重定向 JSON 使用 UTF-8；审核或集成者自行保存本包证据。

## 三轮共同边界

| 阶段 | 当前稳定边界 |
|---|---|
| R1 | 事实、准确 targets、类目/价格/文案/图片缺口；商务平台零写。当前明确授权可涵盖必要付费文案，模型请求单列，不写成零请求 |
| R2 | 消费不可变 R1，母图与本地化、产物身份、QA与采用状态；不写妙手、不建发布计划 |
| R3 | 依有效授权准备妙手写回与准确回读，冻结候选，最终具名目标批准后独立平台执行/回读；接管命令绝不执行此阶段 |

旧 `DEFERRED_TO_SECOND_ROUND` 只作为历史数据标签读取，不能把妙手同步路由回 R2。`ACTIVE` 字样、个人安装目录、页面可打开或源文件存在，都不证明当前工程中某模式已经接通。

## 来源收敛顺序

当前集成基线为已验收的内部 SKU/五核心版本；不覆盖整 server 或已核验的 R1 类目观察/审批绑定。正式工程、运行恢复工程与个人三轮技能先做全文件差异，再按功能迁入、针对验证和完整 manifest 安装。禁止用旧仓库全文覆盖个人较新实现来消除 parity 差异；安装前保全个人独有文件。只读接管使用指定源码入口，不混用个人目录内按 parents 推断工程的脚本。

尚待组合的功能应明确列为待组合，不能写成已统一：manual-intake workbench 支持、个人 R1 完整候选/图片计划侧车与自动决策执行入口、政策加载/本次授权的有界衔接、R2/R3 相应入口与 UI 投影。现有候选中的类别观察、三轮边界、未知付费恢复、最终候选/尝试预算及关闭工具防护保留。当前小包不安装技能、不改个人政策、不切生产数据。
