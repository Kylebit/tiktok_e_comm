四个按钮逐一说明

重新导入采集箱

  1. 读取当前批准的标题、SKU、图片、描述、类目、国家和价格。
  2. 创建一个新的 TikTok / Shopee 妙手采集箱批次。
  3. 旧草稿保留，妙手使用最新草稿。
  4. 页面只显示“导入成功”或“导入失败：原因”。
它只导入草稿，不发布任何店铺；旧草稿存在也不能阻止重新导入。

发布 TikTok

  1. 读取当前选择的 TikTok 国家和店铺。
  2. 带上各站点已经批准的标题、类目和价格。
  3. 调用对应的妙手 TikTok 发布 API。
  4. 所有站点返回成功：显示“TikTok 发布成功”。
  5. 存在失败站点：显示失败站点和妙手返回原因；按钮恢复可点击。
再次点击就是一次全新发布请求，不受上一次成功、失败或不确定结果影响。

发布 Shopee 全球商品

  1. 读取批准的标题、英语母版描述、SKU、图片、类目和价格资料。
  2. 调用妙手 Shopee 全球商品发布 API。
  3. 妙手返回成功：显示“Shopee 全球商品发布成功”。
  4. 妙手返回失败：显示失败原因；按钮恢复可点击。
当前只发布全球商品，不继续发布 PH、MY、TH、VN 等区域站点，也不依赖 TikTok。

发布 Ozon

  1. 读取当前已经批准的 Ozon 商品资料。
  2. 调用独立的 Ozon 妙手发布 API。
  3. 妙手返回成功：显示“Ozon 发布成功”。
  4. 妙手返回失败：显示失败原因；按钮恢复可点击。
Ozon 不依赖 TikTok 或 Shopee，也不会被另外两个平台的历史状态禁用。

页面只保留四种状态

未发布本轮还没有请求妙手 API；按钮可点。
发布中正在等待妙手 API 返回；当前按钮暂时不可重复点。
发布成功妙手 API 返回成功；本次结束，按钮可以再次点。
发布失败显示妙手返回原因；按钮可以再次点。

“本轮执行状态”只显示刚才点击的平台处于上面哪一种状态，不再展示“可准备目标数”“服务端店铺状态”“待确认”“人工验收”或“对账”。

真实浏览器测试要求

  1. 真实点击三个平台按钮，不允许只调用函数代替点击。
  2. 每个平台都测试“妙手成功”和“妙手失败”。
  3. 截图保存“发布中、发布成功、发布失败”三个画面。
  4. 证明一个平台失败时，另外两个平台仍可点击。
  5. 证明成功和失败后都能再次发布。
  6. 桌面和手机宽度都不能有横向溢出，控制台不能出现错误。
按钮必须测试正确结果
发布 TikTok成功 / 失败 / 再次点击只显示成功或失败，不出现验收与对账
发布 Shopee 全球商品成功 / 失败 / 再次点击只影响 Shopee 全球商品
发布 Ozon成功 / 失败 / 再次点击只影响 Ozon
