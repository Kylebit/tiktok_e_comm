# Current finance regression migration (Q01-E)

Base 7361ec7e50ada1499a359c27eeee061642468ade. No production behavior changes.
The four obsolete composite literal tests are replaced by existing captured bridge,
waterfall, sample audit and real Chrome behavior tests listed below. The original
source and 4 failure / 1 pass baseline remain frozen in the Q01-E audit directory.
The existing fifth legacy adapter test remains intact and uses injected data only.

Read-only is checked by unchanged synthetic input bytes and the actual browser
request path, not by whether requests use GET or POST. Bounded local PNG replaces
the old proxy. Exact identity checks replace unsafe cross-platform tail4 inference.
Dynamic fee rows and HTML histogram replace old property/class/canvas literals.
The current /sku-profit link is absent (HTML parser + actual served DOM); Q01-D's
53a57 historical path note is not current evidence. /settlement is a separate tool.

No open gap among these 46 assertions in the limited captured-input scope is
known after verification. This does not prove live collection/provider coverage,
fee-source independence, present-day fee rates, or production data correctness.
Those capabilities are outside the migrated claims, not silently declared restored.
The prior C HTTP Win10053 limitation and original E omitted-fee defect remain in
their original evidence. No skip, xfail or test collection exclusion is added.

`q01_finance_faults` is an opt-in pytest plugin. It wraps actual consumers in memory
and reruns six existing nodes with truncated samples, unknown profit replaced by
zero, unknown affiliation replaced by without, missing optional fees raising,
duplicate fee deduction, and ignored SKU identity. Each must fail; normal execution
must pass. It does not patch files, auto-load, or affect ordinary pytest runs.
