# 东南亚四国逐 SKU 备货决策台

这是供应链运营域内的纯本地、只读决策页面。它不会连接雅仓、TikTok、Shopee 或数据库，也不会自动生成采购单。

页面按国家隔离需求与库存：

- 马来西亚：TikTok MY + Shopee MY，共用雅仓 `MY8803`；25 天补货周期，西马海运，税费节省按用户结算价的 10%。
- 泰国：TikTok TH + Shopee TH，共用雅仓 `TH8806`；15 天补货周期，泰国陆运，税费节省按用户结算价的 15%。
- 越南：雅仓 `VN8805`；15 天补货周期，按越南南部陆运保守价，税费节省按用户结算价的 10%。TikTok 有 31 天 SKU 级结算；Shopee 当前 `BLOCKED_AUTH`，未计入需求。
- 菲律宾：雅仓 `PH8807`；25 天补货周期，马尼拉海运。尚无获批税费优势，按 0。TikTok 有 31 天 SKU 级结算；Shopee 当前 `BLOCKED_AUTH`，未计入需求。
- 四国均以 30 天仓储目标为主，并增加相当于补货周期约 20% 的安全期。
- “海外仓已有 SKU”与“海外仓尚无、可做首批备货”分开显示。首批候选必须具备需求、在售商品、尺寸、重量、成本和本地主图。

在本目录运行：

```powershell
C:\Users\Windows11\Desktop\Agent_PR\tiktok_e_comm\.venv\Scripts\python.exe -m http.server 8874
```

然后打开 `http://127.0.0.1:8874/`。

数据截点为 2026-07-30。头程使用 2026-05-21 报价表，正式发货前应复核当期价格和货物属性。泰国 Shopee 的本地规范化结算快照没有 SKU 级跨境运费字段，因此该部分节省按 0 计，不伪造收益。越南与菲律宾 Shopee 的授权缺口同样不会被解释为零销量。

泰国库存使用显式别名归一化：`990401` 与 `0401` 合并为 `0401`，`990605` 与 `0605` 合并为 `0605`。越南/菲律宾同名猫托盘的仓库记录无法唯一落到 `0820/0821/0822`，因此单列为 `082X` 待分配库存，不抵扣任何具体 SKU。
